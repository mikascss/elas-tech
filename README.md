# ElasTech | Java + IA

Repositório criado para acompanhar minha jornada no bootcamp **ElasTech**, uma iniciativa da **SoulCode Academy em parceria com o PagBank**.

O programa é voltado para o desenvolvimento de conhecimentos em **Java Back-End**, **Inteligência Artificial** e outras tecnologias relacionadas ao desenvolvimento de software.

## Sobre o repositório

Este repositório é utilizado para armazenar:

- Atividades realizadas durante o bootcamp;
- Exercícios desenvolvidos em aula;
- Desafios de programação;
- Exemplos apresentados durante as aulas;
- Anotações e conteúdos de estudo;
- Práticas com Java e conceitos de desenvolvimento Back-End;
- Conteúdos relacionados à Inteligência Artificial.

## Tecnologias

Ao longo do bootcamp, este repositório poderá conter estudos e projetos utilizando tecnologias como:

- Java
- Programação Orientada a Objetos
- Collections
- Tratamento de exceções
- Git e GitHub
- APIs
- Spring Boot
- Banco de Dados
- Inteligência Artificial

> O conteúdo do repositório será atualizado conforme o avanço das aulas e atividades do programa.
